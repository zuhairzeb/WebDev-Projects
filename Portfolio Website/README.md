# Portfolio Website

A simple personal portfolio website built with HTML, CSS, and JavaScript.

## Overview
This repository contains a small static portfolio site intended to showcase projects and responsive layouts.

## Files
- index.html — main page
- styles.css — base styles
- mediaqueries.css — responsive rules
- script.js — interactive behavior
- Preview/README.md — preview notes and screenshots

## Local Setup
1. Open `index.html` in your browser.

Or run a simple local server (recommended for testing JavaScript modules or fetch requests):

```bash
# Python 3
python -m http.server 8000
# Then open http://localhost:8000
```

## Development
- Edit the HTML, CSS, and JS files and refresh the browser to see changes.
- Styles are split between `styles.css` (base) and `mediaqueries.css` (responsive breakpoints).
