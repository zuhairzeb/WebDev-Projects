# Personal Portfolio Website

A modern, responsive personal portfolio website for **Muhammad Zuhair Zeb**, showcasing professional skills, experience, and projects.

## 📋 Features

- **Responsive Design** - Works seamlessly on desktop, tablet, and mobile devices
- **Dark Theme** - Modern dark UI with green accent color (#7cf03d)
- **Smooth Navigation** - Animated page transitions and smooth scrolling
- **Mobile Menu** - Hamburger menu for mobile devices
- **Multiple Sections** - Home, Service, Resume, Portfolio, and Contact sections
- **Social Media Links** - Direct links to GitHub, LinkedIn, and Instagram
- **CV Download** - Easy access to download CV/Resume
- **Interactive Elements** - Dynamic text animations and hover effects

## 📁 Project Structure

```
├── index.html          # Main HTML file
├── style.css           # Styling and layout
├── script.js           # JavaScript for interactivity
├── img/                # Image assets folder
└── README.md           # This file
```

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- No additional dependencies required

### Usage

1. **Clone or download** this repository
2. **Open** `index.html` in your web browser
3. **Navigate** through different sections using the navigation menu

## 🎨 Customization

### Colors
Edit the CSS variables in `style.css`:
```css
:root {
    --bg-color: #1f242d;           /* Background */
    --second-color: #323946;       /* Secondary */
    --main-color: #7cf03d;         /* Accent - Green */
    --white-color: #fff;           /* Text */
    --disable-color: #fff3;        /* Disabled */
}
```

### Content
- Update personal information in `index.html`
- Modify social media links with your profiles
- Replace CV file path with your actual CV
- Add your own images to the `img/` folder
